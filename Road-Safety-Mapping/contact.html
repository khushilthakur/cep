Viva Voce Project Demonstration

During the university viva examination, this platform demonstrates the application of:

  • Spatial GIS data binding using Leaflet & OpenStreetMap
  • Dynamic asynchronous JSON data fetching (zero heavy backend dependency)
  • Reactive Chart.js rendering adapting to user theme preferences
  • Client-side data persistence and export via localStorage & JSON serialization
